# PCOptopus UX

Professional, quiet, specific. Health as care of a tool you depend on — not a threat score.

## Visual

- One accent color; semantic color only for `steady` / `attention` / `act`
- SF Pro for prose; SF Mono for setting keys and before/after values
- Reduce Motion and VoiceOver labels are part of the build
- Window minimum 960×640
- Menu-bar mark: simple octopus; a single dot when an action is waiting or the kill switch is on

## Screens

- **Today** — Pulse score, goal copy (**One goal: Pulse 100**), **Fight for 100** CTA, vitals, last journal row with Undo
- **Machine** — identity card for this Mac
- **Eight domains** — measured fact, sparkline, what good looks like, actions by risk
- **Action** — exact key, previous/next, why, risk, Undo path
- **Contract** — grants off by default; sliders for bounds
- **Journal** — timeline, You / Autopilot filter, Undo
- **Week** — four practices, trends, no percentage score
- **Ask** — coach grounded in stored JSON only
- **Settings** — kill switch, pauses, quiet hours, redacted export

## Copy

Every number has a unit and a comparison. Example: “57 GB available of 460 GB”.
The word “optimize” never appears without the knob it refers to.
